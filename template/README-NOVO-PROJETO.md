# Bem-vindo ao seu novo projeto OpenCode + OpenSpec!

Parabéns! Você acabou de criar um novo projeto com uma configuração profissional completa.

## O que você tem aqui?

- ✅ **29 Agents Especializados** - IAAgents para diferentes domínios
- ✅ **45+ Skills** - Conhecimento domínio-específico
- ✅ **13 Workflows** - Automações com slash commands
- ✅ **OpenSpec Configurado** - Pronto para Spec-Driven Development

## Primeiros passos

1. **Configure seu projeto:**
   ```bash
   npm install
   # Configure seus scripts em package.json
   ```

2. **Inicie o OpenCode:**
   ```bash
   opencode
   ```

3. **Comece a usar OpenSpec:**
   - Digite `/openspec-propose` para propor uma nova feature
   - Explore os exemplos em `openspec/specs/`

## Estrutura do Projeto

```
.
├── .opencode/          # Configuração OpenCode
│   ├── agents/         # 29 agents especializados
│   ├── skills/         # Skills OpenSpec
│   ├── workflows/      # Slash commands (13 workflows)
│   ├── rules/          # Regras customizadas
│   └── memory/         # Convenções do projeto
├── openspec/           # Desenvolvimento Spec-Driven
│   ├── config.yaml     # Configuração OpenSpec
│   ├── specs/          # Especificações de features
│   └── changes/        # Histórico de mudanças
└── package.json        # Configuração Node.js
```

## Workflows Disponíveis

Use estes slash commands no OpenCode:
- `/brainstorm` - Brainstorm de ideias
- `/plan` - Planejar tarefas
- `/create` - Criar novo código
- `/debug` - Debugar problemas
- `/test` - Executar testes
- `/deploy` - Deploy da aplicação
- `/coordinate` - Coordenar múltiplos agentes

E mais 6 outros...

## OpenSpec - Desenvolvimento Dirigido por Specs

Crie specs antes de codificar:

```bash
/openspec-propose
```

Isso abrirá o workflow OpenSpec que:
1. Propõe a feature
2. Cria um plano detalhado
3. Gera tarefas específicas
4. Rastreia o progresso

## Customização

- **Editar agents**: Modifique `.opencode/agents/`
- **Adicionar skills**: Crie novas pastas em `.opencode/skills/`
- **Convenções do projeto**: Edite `.opencode/memory/project-conventions.md`
- **Regras customizadas**: Adicione em `.opencode/rules/`
